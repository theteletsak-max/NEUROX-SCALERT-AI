SNIPER AI v2.00 — Install
=========================

File required:
  SniperAI.mq5

Steps:
  1. MetaTrader 5 → File → Open Data Folder
  2. Copy SniperAI.mq5 into MQL5/Experts/
  3. MetaEditor → open SniperAI.mq5 → Compile (F7)
  4. Attach to chart → Enable Algo Trading

Notes:
  - Single-file institutional build
  - Trade comment is exactly: SNIPER AI
  - Watermark disabled
  - Premium dashboard on the right
  - Demo test first
