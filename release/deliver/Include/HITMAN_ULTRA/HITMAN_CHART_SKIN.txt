HITMAN AI — CHART SKIN INSTALL
==============================

After attaching HITMAN_AI to a chart you should see:
  • Dark chart (black background, orange/red candles)
  • Semi-transparent Hitman character watermark (center)
  • Bottom branding: HITMAN AI + *** ACTIVATED ***
  • Left red HUD panel (symbol, lots, trades, ATR, PosEvo…)

INSTALL IMAGE (required for watermark)
1) Open MT5 → File → Open Data Folder
2) Copy HITMAN_Watermark.bmp into:
      MQL5\Images\HITMAN_Watermark.bmp
   (included in the zip under Images\ and HITMAN_AI_EA\MQL5\Images\)
3) Re-compile HITMAN_AI.mq5 in MetaEditor (embeds #resource)
4) Re-attach EA to the chart

INPUTS (group "HITMAN CHART SKIN")
  EnableHitmanChartSkin = true
  EnableHitmanWatermark = true
  EnableHitmanBranding  = true
  EnableHitmanHudPanel  = true
  WatermarkScalePercent = 70

If the character does not show: confirm the BMP path above, compile again,
and check Experts log for object errors. Branding/HUD still work without BMP.
